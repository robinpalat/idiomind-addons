# Idiomind Addons

**Idiomind Addons** is the collection of extensions that add functionality to Idiomind.

The addons are small and independent pieces that extend the application without having to become part of its core.

Some are practical tools for everyday language learning. Others connect Idiomind with external services or explore ideas that may eventually become part of the main application.

## Addons

The current collection includes:

- **Hard words** — work with difficult or unfamiliar words.
- **Save as audio** — create audio from the contents of a topic.
- **Feeds** — bring external language content into Idiomind.
- **Resources** — provides language resources used by Idiomind.
- **AI Topic Builder** — create language-learning topics with AI.
- **Podcasts** — work with podcast content for language learning.
- **Speech to text** — convert speech into text.
- **User data** — handles user-specific Idiomind data.

## Native addons

Two addons are part of the standard Idiomind installation:

- **User data**
- **Resources**

They are not optional in the same sense as the other addons. They provide parts of the data and resources that Idiomind expects to have available.

The remaining addons can be added according to the user's needs.

## How it fits into Idiomind

The addon system follows the same approach that has shaped Idiomind from the beginning.


A feature can be developed separately, tested separately and added to Idiomind without necessarily becoming part of the core application.

Some addons are simple tools. Some are more experimental. There is no requirement that they all have the same scope or complexity.

## Status

The collection is part of the ongoing development of Idiomind.

Some addons are more established than others, and their implementation may change as the application evolves.
